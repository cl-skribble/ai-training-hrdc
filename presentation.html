Module 1

What Is AI? (In Plain English)

🔍
Concept 1
Pattern Recognition
AI learns from billions of examples — emails, books, websites — and recognises patterns in language the same way you recognise a friend's voice.
💬
Concept 2
Autocomplete on Steroids
A Large Language Model (LLM) predicts what word comes next — but it's so good at this, it can write emails, analyse data, and have real conversations.
🤝
Concept 3
Claude Is Your AI Partner
Claude is built by Anthropic to be helpful, harmless, and honest. Think of it as a very fast, very well-read intern who never gets tired.

💡 The key insight: AI doesn't understand — it predicts. The better your instructions, the better its predictions.

Module 1

Claude.ai vs Claude Code

Two tools, same brain — choose based on what you need.

🌐 Claude.ai
Browser — No installation needed
  • Chat interface, works like WhatsApp for AI
  • Upload images, PDFs, spreadsheets
  • Organise work into Projects

  • Free tier available — start here today
⚡ Claude Code
CLI (Command Line) — More powerful
  • Runs directly on your computer
  • Reads and creates files automatically
  • Builds automations and workflows
  • Connects to apps via MCPs (Module 4)
  • Used for building custom skills
Start with Claude.ai today → Claude Code is your next power-up
Module 1

Writing Effective Prompts

The 3-part formula that turns average results into great ones.

Part 1
ROLE
"You are a senior business consultant…"
+
Part 2
TASK
"Summarise this report for my board…"
+
Part 3
CONTEXT
"Audience: CFOs. Format: 5 bullets. Tone: formal."
✅ Good Prompt

You are my executive assistant. Draft a professional reply to this client complaint. Keep it under 100 words, empathetic, and end with a clear next step. [paste complaint]

❌ Weak Prompt

Reply to this email.

Module 2 · Skills

What Are Skills in Claude Code?

Pre-built, reusable AI workflows — one command, one complex multi-step result.

1
What is a Skill?
A skill is a saved instruction set that Claude Code runs on demand. Think of it like a macro — you trigger it once and it executes a full workflow automatically.
2
How to discover skills
In Claude Code, just type: "find me a skill for [task]" — or use the /find-skills command to browse the library.
3
How to use a skill
Just describe what you want in plain English. Claude Code recognises the intent and invokes the right skill. No commands to memorise.
Example Skills in the Library
🎨 design-system — Extract any brand's CI from a URL
📊 frontend-slides — Generate HTML presentations
🔍 business-analyst — Deep business process analysis
📝 technical-writer — Auto-generate documentation
🔒 security-review — Audit code for vulnerabilities
TRIGGER PHRASE

You don't install manually — just describe the task to Claude Code and it selects the right skill automatically.

The design-system Skill — Brand Intelligence

Give Claude Code any website URL, screenshot, or brand asset. It extracts the full CI and exports a design system + brand book.

What you give Claude Code
🌐 A website URL (e.g. competitor's site)
🖼 A screenshot of their branding

What you get back
🎨 Extracted color palette with hex codes
✍️ Typography choices and weights
💬 Brand voice and tone analysis
📋 Full design system HTML reference page
📄 1-page A4 brand book PDF
How to trigger it in Claude Code:
Step 1 — Extract the CI:
Extract the design system from https://[COMPETITOR-WEBSITE].com Give me their complete brand identity: colors, fonts, brand voice, and generate the design system HTML.
Step 2 — Generate research brief:
Using the CI you just extracted, create a competitive research brief covering: 1. Brand positioning and target audience 2. Key visual and messaging differentiators 3. How they compare to [MY COMPANY] 4. Strategic opportunities for our next pitch

💡 Why this matters: You learn a competitor's brand strategy — not just what they say, but how they position — in under 2 minutes.

Organise your AI conversations by client, topic, or workflow — with memory that persists.

A dedicated workspace in Claude.ai where Claude remembers everything you tell it — across multiple conversations. Like a brief for a long-term working relationship.

Add documents

Example Projects to Create

📁 Client: [Company X] — all work for one client
📁 Weekly Reports — auto-format your updates
📁 HR / Hiring — job descriptions, interviews
Module 3

Custom Instructions — Your Personal Rules

Tell Claude who you are and how you want it to behave — once. Forever.

Custom instructions are a set of permanent guidelines you give Claude at the Project level. Claude applies them to every conversation in that Project automatically.

Template Structure
🎭 ROLE: "You are my executive assistant..."
👤 CONTEXT: Your name, company, industry, role
📋 BEHAVIOURS: "When I send emails, do X"
✍️ STYLE: Tone, language, format preferences
Example custom instruction:
You are my executive AI assistant. About me: - Name: [YOUR NAME] - Company: [COMPANY NAME] - Title: [YOUR ROLE] - Industry: [INDUSTRY] When I share emails: summarise in 3 bullets, list action items When I share meeting notes: extract tasks with owner + deadline When I ask for reports: formal language, include exec summary first When I ask for emails: professional, concise, warm closing Always respond in English. Keep responses under 300 words unless I ask for more.
